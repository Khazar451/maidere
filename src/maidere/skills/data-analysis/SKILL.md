# Data Analysis & Processing

## Instructions

2. Handle missing/null values explicitly.
3. Generate clear summaries with descriptive statistics (mean, median, standard deviation).
4. Write and run modular Python scripts via `code_runner` tool.
5. Save generated tabular outputs or clean CSVs inside the `workspace/` directory.
